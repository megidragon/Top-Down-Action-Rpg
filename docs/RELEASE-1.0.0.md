# El Tesoro del Bosque — v1.0.0 🏹🌲

**First complete playable version.**

Legend has it that an unclaimed treasure sleeps in the heart of the kingdom's
most dangerous forest. Many went in to find it. None came back. Today it's
your turn.

## ✨ What's in this version

- **4 playable classes** with their own identities: Warrior (balanced), Lancer
  (reach and punch, heavy tempo), Archer (telegraphed arrow rain and ranged
  bursts) and Monk (area heal, kicks that send enemies flying and a steerable
  stunning charge).
- **Real-time action combat**: 130° fan sweeps, thrusts, a directional parry
  that blocks any hit (arrows included!), dash and energy management.
- **A 10-level roguelike** inside the forest, with rising difficulty
  (+1 enemy every 3 levels) and enemies of all 4 classes with their own AI.
- **A lively starting town** and **rest camps** with a healing campfire and
  merchants: 1/2/3-use potions and permanent elixirs of strength, defense
  and speed.
- **Stats system** (strength / defense / speed) that grows over the run by
  buying elixirs.
- **Economy**: enemies drop coins that you pick up by walking close.
- **Full menus**: title screen, settings (resolution, fullscreen, screen
  shake, volumes, **Spanish/English** language) and pause menu (ESC).
- Windows installer.

## 🎮 Controls

| Action | Control |
|---|---|
| Move | WASD |
| Dash | Shift |
| Primary attack | Left click |
| Special attack | Right click |
| Parry / Heal (Monk) | Space |
| Use item | 1–4 |
| Interact / Buy | E |
| Pause | ESC |
